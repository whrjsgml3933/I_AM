# SSAFY.MATE — 인터랙티브 자기소개 페이지

SSAFY 16기 온보딩 개인 프로젝트입니다. 식사·스터디·취미 관심사를 선택하면 조합에 맞는 소개 문구를 보여주는 단일 HTML 페이지입니다.

## 구현 내용

- 관심사 체크박스 조합에 따른 매칭 티켓 문구 변경과 복사
- 연락처 표시·복사 및 토스트 알림
- 라이트·다크 테마 전환과 브라우저 내 테마 저장
- Canvas 배경 파티클과 화면 크기에 따른 반응형 배치

**기술:** HTML, CSS, JavaScript, Tailwind CSS CDN, Lucide 아이콘.

## 실행

[index.html](index.html)을 브라우저에서 열거나, 저장소 루트에서 다음 명령을 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 에 접속합니다. Python은 정적 파일 제공에만 사용합니다. CDN 스타일·아이콘 로딩에는 인터넷 연결이 필요합니다.

## 확인할 흐름

1. 식사·스터디·취미를 선택하고 티켓 문구가 바뀌는지 확인합니다.
2. 티켓 복사 버튼과 연락처 표시·복사 동작을 확인합니다.
3. 테마를 전환하고 새로고침 후 선택이 유지되는지 확인합니다.
4. 모바일 너비에서 배치와 배경 효과를 확인합니다.

## 구현 범위

자기소개와 상호작용을 보여주는 정적 페이지입니다. 실제 사용자 매칭, 계정 인증, 서버 저장 기능은 없습니다. 연락처 표시 버튼은 화면 표시를 전환하는 기능이며 접근 권한을 보호하는 인증 기능은 아닙니다.

기존 임시 호스팅 주소와 QR은 지속적인 접속을 보장하지 않아 실행 안내에서 제외했습니다. 현재 확인 가능한 소스는 이 저장소의 HTML입니다.
